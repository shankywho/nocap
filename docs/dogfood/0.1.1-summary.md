All six fixes are done and pushed to `origin/main`, with small commits and a test for each. I didn't publish; the 0.1.1 tarball is built at `.cache/pack-cli/shankywho-nocap-0.1.1.tgz`.

1. **Offline mode:** `nocap config set llm-key` and `nocap config get` work. The file is mode 600 and the key is never printed. The key is read from `NOCAP_LLM_API_KEY`, `GROQ_API_KEY`, `LLM_API_KEY`, then the config file. With no key, a dim banner prints, and the RESULT line ends in `· offline` or `· gpt-oss-120b@groq`. "Added `x()` in <path>" now gives both `symbol_added` and `file_modified`.
2. **Hygiene:** the excluded directories and `*.log` never reach snapshots or ChangeSets, even without a `.gitignore`. UNDISCLOSED stops at 15 lines plus "…and N more (see receipt JSON)". Lockfiles show as one quiet "lockfile changed" line and don't make a run MIXED.
3. **Bitecheck on new symbols:**
   - Added functions are stubbed to `return undefined` (`return None` in Python). They are no longer deleted.
   - Modified existing functions go back to their base bodies.
   - Receipts record `mode` and `stubbed`. The result prints as `bites (stub)` or `toothless (stub)`.
   - A test asserting only `typeof mul === 'function'` comes back TOOTHLESS. A test asserting `mul(2,3) === 6` comes back BITES.
   - `docs/BITECHECK.md` is updated.
   - The `untracked` scenario now expects `bites` instead of `import_only`, because it adds a new function.
4. **Fixture leak:** git for fixtures only runs strictly inside the cache, with `GIT_CEILING_DIRECTORIES` set. Without that ceiling, git commits to the parent repo when the fixture's own `.git` is missing. That is the probable cause of the leaked commit. I confirmed it in a throwaway repo, and the new test checks the main repo's HEAD and author are unchanged.
5. **`node --test`:** projects with a `node --test` script are detected and run with the junit reporter, one process per file. I verified the flags on the installed Node v24.11.0 only. The earliest Node with the junit reporter was not verified, so an older Node produces an environment result, never a ✗. This is logged in `DECISIONS.md`.
6. **Release:** version is 0.1.1, `repository` and `homepage` point to `github.com/shankywho/nocap`, and the changelog and goldens are updated.

**Checks**
- **Test run:** 301 tests plus lint and typecheck pass.
- **Packed CLI:** I ran `npx ./pkg.tgz check` on fresh repos. A run with no key printed the banner and `· offline`. A typeof-only test was ✗ `toothless (stub)`, a value-asserting test was ✓ `bites (stub)`, and `config set` wrote a mode-600 file.
